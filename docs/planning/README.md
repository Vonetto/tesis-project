# Planning del Proyecto

Esta carpeta es la **ubicación canónica** para la documentación de planning del proyecto.

La organización se divide en dos capas:

- `workstreams/`: documentación viva y operativa por línea de trabajo.
- `stages/`: síntesis histórica por etapa del proyecto.

## Regla de uso

### `workstreams/`
Usar para trabajo activo.

Cada workstream mantiene:

- `notes.md`: bitácora cronológica
- `task_plan.md`: checklist, milestones y próximos pasos

Todo avance nuevo se registra aquí. Esta es la **fuente de verdad operativa**.

### `stages/`
Usar para ordenar la historia metodológica del proyecto.

Cada stage mantiene:

- `notes.md`: síntesis consolidada
- `task_plan.md`: ficha resumida de estado y artefactos

No debe replicar el detalle diario de `workstreams/`. Se actualiza solo al cerrar hitos o consolidar una etapa.

## Estado de migración

- La estructura nueva vive en `docs/planning/`.
- El contenido antiguo en `docs/plans/tesis-project/` queda como **legacy temporal** mientras se consolida la migración.
