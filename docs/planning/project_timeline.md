# Timeline del Proyecto

- **Septiembre 2025**: bootstrap del repo, ingesta inicial, joins base y primeros EDA.
- **Octubre 2025**: limpieza/anomalías y consolidación del pipeline de calidad.
- **Octubre-Noviembre 2025**: primera línea de modelos logit binarios y nested.

- **Marzo 2026**: expansión a workstreams de modelamiento OD-buffers, refinamiento y contexto interanual.
