\section{Resultados de parámetros en formato wide}

\subsection{Opción A: \texttt{BIP} como referencia para variables comunes}

La Tabla~\ref{tab:parametros_opcion_a} presenta los parámetros del modelo bajo la primera
normalización considerada. En esta especificación, \texttt{BIP} se mantiene como alternativa de
referencia para las variables comunes al conjunto de alternativas. Por lo tanto, para variables como
año, franja horaria, demanda, oferta, Censo y OSM, el coeficiente de \texttt{BIP} se fija en cero y
los coeficientes de \texttt{QR\_OTHER} y \texttt{QR\_RED} se interpretan respecto de esa alternativa
base.

Esta normalización no implica que dichas variables no estén asociadas a la elección de
\texttt{BIP}. Más bien, implica que el efecto se expresa en términos relativos: un coeficiente
positivo para \texttt{QR\_RED}, por ejemplo, indica que un aumento en la variable incrementa la
utilidad de \texttt{QR\_RED} respecto de \texttt{BIP}, manteniendo todo lo demás constante. Para las
variables que sí varían entre alternativas dentro de un mismo viaje, como tiempos y transbordos,
también se estima directamente un coeficiente para \texttt{BIP}.

Se presentan los coeficientes estimados y sus estadísticos \emph{t-ratio} robustos. Una versión
extendida de la tabla, que incluye errores estándar robustos, se deja en el
Anexo~\ref{sec:anexo_parametros_completos}. Los ceros reportados para \texttt{BIP} en variables
comunes corresponden a restricciones de normalización y no a parámetros estimados.

\subsection{Opción B: coeficientes reportables bajo suma cero}

La Tabla~\ref{tab:parametros_opcion_b} presenta los parámetros del modelo bajo la segunda
normalización considerada. A diferencia de la Opción A, esta parametrización permite reportar
coeficientes para \texttt{BIP}, \texttt{QR\_OTHER} y \texttt{QR\_RED} también en variables comunes al
conjunto de alternativas. Esta forma de presentar los resultados puede ser más informativa cuando el
interés es comparar directamente el signo y magnitud de cada variable entre las tres alternativas.

En esta parametrización, los coeficientes de variables comunes se identifican mediante una
restricción de suma cero entre alternativas. Es decir, para cada variable común $x_k$ se impone que
\[
\beta_{\texttt{BIP},k}
+ \beta_{\texttt{QR\_OTHER},k}
+ \beta_{\texttt{QR\_RED},k}
= 0.
\]
Por lo tanto, el coeficiente de \texttt{BIP} no se estima como un tercer parámetro libre, sino que se
recupera como
\[
\beta_{\texttt{BIP},k}
= -\left(\beta_{\texttt{QR\_OTHER},k}+\beta_{\texttt{QR\_RED},k}\right).
\]
Esto permite reportar coeficientes para las tres alternativas, manteniendo identificada la utilidad.
Sin embargo, para los coeficientes de \texttt{BIP} derivados por suma cero no se reportan errores
estándar ni estadísticos \emph{t-ratio}, ya que estos requerirían calcularse explícitamente mediante
el método delta usando la matriz de varianzas y covarianzas. Por esta razón, en la tabla principal y
en la tabla extendida del anexo, el \emph{t-ratio} de \texttt{BIP} aparece solo para las variables
alternativa-específicas estimadas directamente.
